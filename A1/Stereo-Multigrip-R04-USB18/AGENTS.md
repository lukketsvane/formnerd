# CAD- og printleveranse

Brukaren har frå 27. oktober 2026 uttrykkeleg bede om å samle alle delar i same prosjektfil og oppdatere denne vidare, framfor å opprette mange printfiler. Følg denne preferansen i vidare arbeid med prosjektet.

- Bruk det stabile leveransenamnet `ENTROPI_MASTER.3mf` og bevar den same lagra filidentiteten ved oppdatering.
- Samle alle printdelar som namngjevne objekt og plater i masterfila. Oppdater endra delar på plass; ikkje legg gamle variantar eller ekstra kopiar inn som utilsikta printobjekt.
- Behald redigerbar CAD, kjeldekode, delmanifest og kontrollgrunnlag saman med masteren, gjerne inne i 3MF-pakken. Separate mellomfiler er arbeidsgrunnlag, ikkje nye leveransar.
- Opprett ei separat printleveranse berre ved uttrykkeleg bestilling eller eit nødvendig format-/skrivarkrav. Bevar eldre leveransar; ikkje slett dei som opprydding utan instruks.
- Bruk faktisk modellgeometri til tekniske rendringar. Skil digital CAD-/slicer-kontroll frå fysisk prøvepass og faktisk start av print.

Tidlegare namngjevne 3MF-filer i dette repositoriet er historisk grunnlag. Brukarpreferansen over gjeld nye leveransar og vidare oppdateringar.
