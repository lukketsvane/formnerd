# Materialstudiar

Desse sju bileta er tidlegare AI-genererte forslag til materiale, fargar og finish. Dei dokumenterer visuelle retningar og er ikkje geometrisk dokumentasjon for v05.

Dei sju faktiske CAD-rendringane ligg i [Entropi-CAD-v05/preview](../../Entropi-CAD-v05/preview/). Kjeldenamn og kontrollsummar for studiane ligg i [manifest.json](manifest.json).
