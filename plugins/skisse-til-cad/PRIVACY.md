# Privacy for Skisse til CAD

Publisher: Iver Finne. Effective 21 October 2026.

Skisse til CAD is a skill package containing workflow instructions and reference files. The package includes no publisher-operated backend, account system, analytics or telemetry. Its instructions do not direct your sketches, CAD models, API keys or generated files to Iver Finne.

When you run the workflow, your chosen agent host processes the conversation and attached files under its own policies. Tripo receives the inputs you authorize for its API or CLI. Other selected CAD, image-generation, storage and GitHub services process data under their own policies. A file saved to your Space, repository or other destination is governed by that destination's access settings.

Keep API keys in the provider's supported local credential mechanism or environment. Do not put keys in prompts, public repositories, source packages or support issues.

The package defines no publisher upload-storage service or retention period. Manage conversation, task and file retention with the host and providers you use. Any material you choose to post in the support issue tracker is separate from workflow uploads.

If you submit a GitHub issue, its contents and your GitHub identity are visible under GitHub's issue and account settings. Do not include private models or personal information there. You can edit your issue and request removal of project-controlled content through the issue tracker. This does not remove copies retained by GitHub or other services.

Questions: use the [support page](SUPPORT.md).
