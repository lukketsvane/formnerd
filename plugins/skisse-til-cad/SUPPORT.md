# Support for Skisse til CAD

Publisher: Iver Finne.

Report installation problems, documentation errors or reproducible workflow issues through the [FormNerd issue tracker](https://github.com/lukketsvane/formnerd/issues). Mention Skisse til CAD, the package version, agent/client, operating system and relevant tool versions. Include a minimal non-sensitive example and remove credentials, private download links and personal files.

GitHub issues are public. For Tripo billing, account access or service availability, use Tripo's own support. This project does not operate Tripo or OpenAI services. No response time or ongoing support schedule is promised.
